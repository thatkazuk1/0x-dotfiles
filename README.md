## About the Project

This repository houses my configuration files for a bespoke Linux environment centered around **Hyprland** (a dynamic tiling Wayland compositor). It features a highly integrated, aesthetically pleasing, and functionally rich workspace. The setup seamlessly weaves together multiple modern components:

- A dynamic color extraction engine that alters the entire system theme based on the wallpaper.
- A highly customized, widget-rich control center powered by Eww.
- A versatile status bar configured via Waybar, fully integrated with Google Calendar and system services.
- A unified notification daemon (SwayNC) and dynamic launcher (Wofi).

Everything is managed via GNU Stow to keep the home directory clean and version-controlled.

## Getting Started

### Dependencies

To fully utilize this environment, the following core dependencies must be installed:

- **Hyprland** (Wayland Compositor)
- **Waybar** (Status Bar)
- **Eww** (Elkowars Wacky Widgets - used for the Control Center)
- **SwayNC** (Notification Daemon)
- **Wofi** (App Launcher)
- **Matugen** (Dynamic Color Generator)
- **GNU Stow** (Dotfiles Manager)
- **wf-recorder** & **slurp** (Screen recording)
- **hyprshot** (Screenshots)
- **waybar-ycal** (Google Calendar integration for Waybar)

### Technology Stack

- **Configuration:** Yuck (Eww), JSON/JSONC (Waybar), TOML (Matugen)
- **Styling:** SCSS, CSS (Variables driven by Matugen)
- **Scripting:** Bash, Python

### Third-party Services

- **Google Calendar & Tasks API**: Used by `waybar-ycal` to display events and tasks directly on the desktop.

## Installation & Development

### Setting Up

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shokunbi/dotfiles.git ~/Documents/0s1s/shokunbi/dotfiles
   cd ~/Documents/0s1s/shokunbi/dotfiles
   ```

2. **Install using the script:**
   The repository includes a bootstrap script that installs `stow` (if missing) and automatically creates symlinks to `~/.config/`.
   ```bash
   ./install.sh
   ```

3. **Reload your environment:**
   Log out and log back into your Hyprland session to allow the compositor and associated daemons to load the new configurations.

### Development

To modify the theming engine, refer to `~/.config/hypr/scripts/set-theme.sh`. This script is the entry point for generating Matugen colors from the current wallpaper.

For Eww panel changes, the source files are modularized under `~/.config/eww/panel/src/`. Modifying these files and saving them will dynamically reload the Eww daemon if running.

### Testing

You can test Eww widgets independently by opening them manually via CLI:
```bash
eww open <window_name>
```
To preview colors generated by Matugen without applying them system-wide, use the Matugen CLI directly against an image file.
